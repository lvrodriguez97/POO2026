# POO2026

Repositorio del curso de **Programación Orientada a Objetos** (2026).

Aquí se almacenan los talleres desarrollados durante el semestre, aplicando los conceptos de abstracción, encapsulamiento, herencia y polimorfismo.

## Estructura del repositorio

```
POO2026/
└── Talleres/
    ├── Taller01/
    ├── Taller02/
    ├── Taller03/
    └── ...
```

Cada carpeta `TallerXX` contiene la solución completa del taller correspondiente: las clases que modelan las entidades y sus respectivas clases de prueba (con el prefijo `Test`).

## Convenciones

- Nombres de clases, atributos, métodos y variables en **inglés**.
- Nombres descriptivos que representen adecuadamente el elemento que modelan.
- Clases de prueba nombradas como `Test` + nombre de la clase (ej. `Product` → `TestProduct`).
- Los mensajes al usuario en las clases de prueba pueden estar en español o inglés.
